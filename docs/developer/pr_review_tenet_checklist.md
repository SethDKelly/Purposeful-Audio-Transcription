# PR Review Tenet Checklist

Use this checklist when reviewing application changes.

## Core Question

Does this change strengthen the Relationship Reasoning Engine as an evidence-linked, confidence-calibrated, non-diagnostic, multi-lens structured reasoning platform?

---

# Checklist

## Evidence Traceability

- [ ] New findings/claims cite evidence where appropriate.
- [ ] Evidence quote IDs are valid.
- [ ] Evidence snippets are concise.
- [ ] Users can expand to context if needed.
- [ ] Transcript edits do not invalidate old report evidence.

## Confidence Calibration

- [ ] Claims include appropriate confidence.
- [ ] Inferred claims are not overstated.
- [ ] Alternative explanations are included where relevant.
- [ ] Single-transcript limitations are acknowledged.

## Multi-Lens Analysis

- [ ] Module/lens provenance is preserved.
- [ ] Synthesis distinguishes convergence from divergence.
- [ ] No single lens dominates without evidence.

## Non-Diagnostic Discipline

- [ ] No diagnostic claims are introduced.
- [ ] No definitive personality disorder labels.
- [ ] No unsupported abuse/manipulation determinations.
- [ ] Intent is not stated as fact without direct evidence.

## Longitudinal Case Tracking

- [ ] Case-level evidence includes transcript/session identity.
- [ ] Quote IDs are not treated as globally unique across transcripts.
- [ ] Recurring-pattern claims cite multiple sessions when needed.

## Professional Workflow Fit

- [ ] Outputs remain reviewable.
- [ ] Exports remain transparent.
- [ ] Feedback/review workflows are preserved or improved.
- [ ] Version metadata is preserved.

## Safety-Aware Framing

- [ ] Serious safety concerns are not mutualized.
- [ ] Safety mode is triggered where appropriate.
- [ ] Risk language remains cautious and evidence-limited.
- [ ] Unsafe reconciliation/coaching pressure is avoided.

## Structured Reasoning Graph

- [ ] Findings map cleanly to constructs where applicable.
- [ ] Relationships have type, confidence, rationale, and evidence where possible.
- [ ] Graph merge preserves evidence.
- [ ] Graph output remains inspectable.

## Authentication / Privacy

- [ ] Protected resources enforce ownership.
- [ ] React does not rely on public shared API keys for real users.
- [ ] Sensitive raw outputs are not exposed through normal product APIs.
- [ ] Audit events are created where appropriate.
