# Planning README Update — Tenet-Oriented Roadmap

## Suggested Addition to `docs/planning/README.md`

The active roadmap is now guided by the application core tenets:

- evidence traceability
- confidence calibration
- multi-lens analysis
- non-diagnostic discipline
- longitudinal case tracking
- professional workflow fit
- safety-aware framing
- structured reasoning graph

Planning should prioritize features that strengthen these tenets.

## Current Phase Sequence

The recommended next work is the numeric v2.1 phase sequence:

```text
001 — v2.1 Phase Sequence Overview
002 — Core Tenets and Governance
003 — Simple Email Auth and Ownership
004 — Evidence Precision
005 — Evidence Snapshots and Versioning

```

## Backlog Rule

Any proposed feature that does not strengthen the core tenets should be moved to future consideration unless it is required for reliability, security, or external readiness.

## Market-Agnostic Rule

Do not specialize the application for one market yet.

The system should remain useful for:

- clinicians
- mediators
- coaches
- enterprise leadership facilitators
- educators
- researchers
- supervised couple/client workflows

Specialization should later happen through:

- workflow templates
- report language
- permissions
- exports
- UI presets
